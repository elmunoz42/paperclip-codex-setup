# ADR-002: Validate one content thin slice before expanding automation

- **Status:** Accepted, 2026-09-04
- **Context:** The strategy spans editorial production, a course, WordPress, and an immersive application. Prematurely scaling agents or platform work risks coordination overhead.
- **Decision:** Prioritize one cited, review-ready YouTube package and its companion outline. Use the resulting feedback to shape the next roles and tools.
- **Consequences:** Product work begins with discovery, not implementation; no publication is automated.
- **Owner / revisit:** Carlos; revisit after the first reviewed package.
